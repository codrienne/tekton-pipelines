# Pipeline API v1

This directory contains the API definitions for Tekton Pipelines v1.

## Purpose

This API defines the core resources for creating and managing pipelines, including:

*   **Pipelines:** Define a series of tasks to be executed.
*   **PipelineRuns:** Instances of pipeline executions.
*   **Tasks:** Define individual units of work within a pipeline.
*   **TaskRuns:** Instances of task executions.
*   **Workspaces:** Define shared data volumes between tasks.
*   **Artifacts:** Define data outputs from tasks.
*   **Params:** Define parameters passed to tasks.
*   **Results:** Define results from tasks.
